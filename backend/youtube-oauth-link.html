🎬 YouTube OAuth Renewal

Para renovar tu token de YouTube y publicar el vídeo, sigue estos pasos:

PASO 1: Haz clic en el botón de abajo

Google te pedirá autorización para que la app acceda a YouTube.

✅ AUTORIZAR YOUTUBE
PASO 2: Cuando hagas clic

Se abrirá una ventana de Google. Haz login con tu cuenta y haz clic en "Permitir".

PASO 3: Vuelve aquí

Cuando autorices, verás una página que dice "✅ Éxito". El token se habrá renovado automáticamente.

ℹ️ Nota: El servidor está esperando en localhost:3000. Asegúrate de que no hay nada bloqueando ese puerto.

¿Necesitas ayuda? El servidor capturará automáticamente el código cuando autorices.
