## HOOK 1: Sesgo Cognitivo Simple
```
"Tu cerebro te está [ENGAÑANDO / MINTIENDO] sobre esto"
[pausa visual 1s]
"Se llama [NOMBRE DEL SESGO]"
```
**Temas aplicables:**
- Sesgo de confirmación
- Efecto ancla
- Ilusión de control
- Efecto Dunning-Kruger

**Ejemplo con sesgo confirmación:**
"Tu cerebro te está mintiendo sobre esa persona"
[pausa]
"Se llama sesgo de confirmación"

## INTEGRACIÓN EN GENERADOR_VIDEOS

Para automatizar hooks virales, el sistema puede:

1. **Seleccionar Hook Aleatorio** (⭐⭐⭐⭐⭐ prioritario)
```python
selected_hook = random.choice([hook1, hook2, hook3, hook4])
```

2. **Personalizar con Tema del Vídeo**
```python
hook = selected_hook.format(TEMA=video_topic)
```

3. **Agregar Closure Abierto Aleatorio**
```python
closure = random.choice(closures_abiertos)
```

4. **Insertar en Template de Script**
```python
script = f"{hook}\n[pausa visual]\n{explicacion}\n{closure}"
```

**Resultado:** Cada vídeo genera automáticamente con hook + cierre viral

## CHECKLIST: ¿Tu Hook Es Viral?

Antes de usar un hook, verifica:

```
☐ ¿Genera curiosidad en primeros 0.5s?
☐ ¿El usuario quiere saber la respuesta?
☐ ¿Es relatable (el usuario se ve reflejado)?
☐ ¿Usa una palabra fuerte (engaño, sabotaje, verdad)?
☐ ¿Tiene pausa visual después?
☐ ¿Promete algo (explicación, sorpresa)?
☐ ¿No es genérico ("5 tips", "aprende esto")?
☐ ¿Cierra con pregunta abierta?
```

Si respondes SÍ a 6+, el hook es viable para viralidad.
